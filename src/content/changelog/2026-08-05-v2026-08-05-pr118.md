# v2026.08.05-pr118 - Enhance user experience with new features and translations

## Summary
Latest user-facing updates, improvements, and fixes in RSMethods.

## New
- The admin panel now includes a concurrent users history chart with 72h, 30d, and 1y views. (#116)
- Active session reporting in the admin overview now shows a clearer unavailable state when live presence data cannot be retrieved. (#116)
- The admin panel now shows a live estimate of active sessions across anonymous visitors and signed-in users. (#115)
- Roadmaps can now ignore selected method tags before generating a plan. (#114)
- Roadmap results now show full inputs, outputs, and consolidated requirements for the entire path. (#114)
- Fixed an issue where the page could stay unscrollable after closing certain overlays. (#114)
- Method variants now require both `Actions/hr` and `Action type` before they can be saved. (#113)
- Fixed an issue where variant action metrics were not fully included when creating or updating a method. (#113)
- Improve variant selector interactions and environment visibility (#104)

## Improved
- Users who have not set an account username are redirected to onboarding before accessing complete-profile routes. (#117)
- Backend account username requirement errors now open a modal dialog that guides users to set their account username. (#117)
- Onboarding validation and username conflict handling are improved for a smoother account completion flow. (#117)
- Added a new Roadmaps page where you can generate a skill training path from your OSRS username, target level, and preferred strategy. (#112)
- Roadmaps now show step-by-step method recommendations with estimated time, profit range, AFK level, and direct links to each method. (#112)
- You can now sign in from the login page with your Google account. (#110)
- Login now returns you to the page you were trying to access after Google sign-in completes. (#110)

## Fixed
- Address changelog and review feedback (#109)
- The landing page, changelog, wiki, account screens, and skilling views now use consistent English copy. (#106)
- Older wiki links that used Spanish category slugs still open the correct content. (#106)
